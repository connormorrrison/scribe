# Scribe

iPad app (SwiftUI, iPadOS 18+). The Xcode project is generated from `project.yml` with XcodeGen: run
`xcodegen generate` after adding or removing files.

Follow the design rules in [DESIGN.md](DESIGN.md), especially typography: SF Pro Rounded for UI (two weights at
most: regular and semibold), and Caveat for everything the agent draws or writes.
